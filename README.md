# Delivery contracts

Framework-independent initial delivery over the existing exact PP snapshot.
This package owns bounded document/asset/readiness envelopes, never canonical
data, executable UI, source availability decisions or transport protocols.
Sites supply exact identities and Scene declarations. Hatter supplies owner
readiness. The server only projects it. First render compares the complete
projection key/revision/lineage with the delivered initial identity.

The only live transport is Crowsi STATE. Remote metadata cannot add scripts,
styles, HTML, renderer constructors or new action dispatch functions. Trusted
assets are release-manifest entries, not URLs supplied by HAT packages.
